# Venera 2.1.7

## Changes

- Move Real-CUGAN image decoding, input conversion, cache validation, and output composition to serialized background isolates.
- Limit outstanding upscale jobs to four. Gallery prefetches use source images and do not occupy the visible-page upscale queue. If the queue is full, the page shows the source image and offers retry.
- Cancel pending work when the reader changes chapter or closes. Deduplicate requests for the same image and retain clear task status.
- Serialize F12 fullscreen transitions, restore windowed mode when the reader closes, and release animation state when a page transition is canceled.
- Keep the fullscreen toolbar icon in sync with the current state.

## Verification scope

- 31 Flutter tests passed locally.
- The Windows GitHub Actions workflow must pass analysis, tests, and a Windows release build before this workflow creates a Release.
- No interactive regression test on a physical Windows device was available. Real reader frame times, memory use, crash behavior, and parity with other comic readers remain unverified.
